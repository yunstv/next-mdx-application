Label

Renders an accessible label associated with controls.

import * as Label from '@radix-ui/react-label';

import './styles.css';



const LabelDemo = () => (

  <div style={{ display: 'flex', flexDirection: 'column', gap: 10 }}>

    <Label.Root className="LabelRoot" htmlFor="firstName">First name</Label.Root>

    <input className="Input" type="text" id="firstName" defaultValue="Pedro Duarte" />

  </div>

);



export default LabelDemo;

Installation

npm install @radix-ui/react-label

Anatomy

import * as Label from '@radix-ui/react-label';



export default () => <Label.Root />;

API Reference

Root

Renders a <label> with extra niceties such as preventing text selection on double-click.

Accessibility

This component is a drop-in replacement for the native <label> element. Use htmlFor to associate it with a form control.
