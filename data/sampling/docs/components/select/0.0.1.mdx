## Installation

```bash
npm install @radix-ui/react-select
```

## Anatomy

```jsx
import * as Select from '@radix-ui/react-select';

export default () => (
  <Select.Root>
    <Select.Trigger>
      <Select.Value />
      <Select.Icon />
    </Select.Trigger>
    <Select.Portal>
      <Select.Content>
        <Select.Viewport>
          <Select.Item>
            <Select.ItemText />
            <Select.ItemIndicator />
          </Select.Item>
        </Select.Viewport>
      </Select.Content>
    </Select.Portal>
  </Select.Root>
);
```

## API Reference

### Trigger / Value / Icon
The button that opens the listbox and shows the selected value.

### Content / Viewport / Item
The popup containing the list of selectable items.

## Accessibility

Adheres to the [ListBox WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/listbox) and supports type-ahead, keyboard navigation, and form integration.
