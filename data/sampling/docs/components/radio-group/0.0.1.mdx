## Installation

```bash
npm install @radix-ui/react-radio-group
```

## Anatomy

```jsx
import * as RadioGroup from '@radix-ui/react-radio-group';

export default () => (
  <RadioGroup.Root>
    <RadioGroup.Item>
      <RadioGroup.Indicator />
    </RadioGroup.Item>
  </RadioGroup.Root>
);
```

## API Reference

### Root
Contains the radio items. Holds the selected `value`.

### Item
A single radio button.

### Indicator
Renders only when the item is checked.

## Accessibility

Adheres to the [Radio Group WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/radio) and supports arrow-key navigation.
