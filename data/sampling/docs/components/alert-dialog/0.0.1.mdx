## Installation

```bash
npm install @radix-ui/react-alert-dialog
```

## Anatomy

```jsx
import * as AlertDialog from '@radix-ui/react-alert-dialog';

export default () => (
  <AlertDialog.Root>
    <AlertDialog.Trigger />
    <AlertDialog.Portal>
      <AlertDialog.Overlay />
      <AlertDialog.Content>
        <AlertDialog.Title />
        <AlertDialog.Description />
        <AlertDialog.Cancel />
        <AlertDialog.Action />
      </AlertDialog.Content>
    </AlertDialog.Portal>
  </AlertDialog.Root>
);
```

## API Reference

### Root
Contains all the parts of an alert dialog.

### Trigger
A button that opens the dialog.

### Content
Contains content to be rendered when the dialog is open.

### Cancel / Action
Buttons for cancellation and confirmation. The cancel button should always be present for dismissal.

## Accessibility

Adheres to the [Alert and Message Dialogs WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/alertdialog).
