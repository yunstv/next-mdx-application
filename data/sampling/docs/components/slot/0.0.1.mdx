## Installation

```bash
npm install @radix-ui/react-slot
```

## Anatomy

```jsx
import { Slot } from '@radix-ui/react-slot';

const Button = ({ asChild, ...props }) => {
  const Comp = asChild ? Slot : 'button';
  return <Comp {...props} />;
};
```

## API Reference

### Slot
Forwards its props and ref onto its single child. Useful for the `asChild` composition pattern.

## Accessibility

Slot is a structural primitive — it inherits any a11y semantics from the rendered child element.
