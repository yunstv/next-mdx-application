## Installation

```bash
npm install @radix-ui/react-tabs
```

## Anatomy

```jsx
import * as Tabs from '@radix-ui/react-tabs';

export default () => (
  <Tabs.Root>
    <Tabs.List>
      <Tabs.Trigger />
    </Tabs.List>
    <Tabs.Content />
  </Tabs.Root>
);
```

## API Reference

### List / Trigger
The bar of tab triggers.

### Content
The panel associated with each trigger via `value`.

## Accessibility

Adheres to the [Tabs WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabpanel).
