## Installation

```bash
npm install @radix-ui/react-checkbox
```

## Anatomy

```jsx
import * as Checkbox from '@radix-ui/react-checkbox';

export default () => (
  <Checkbox.Root>
    <Checkbox.Indicator />
  </Checkbox.Root>
);
```

## API Reference

### Root
Contains all the parts of a checkbox. Holds the state and accepts `checked` / `defaultChecked`.

### Indicator
Renders only when the checkbox is in a checked or indeterminate state.

## Accessibility

Adheres to the [Tri-State Checkbox WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/checkbox).
