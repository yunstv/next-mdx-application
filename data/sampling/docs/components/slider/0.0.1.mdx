## Installation

```bash
npm install @radix-ui/react-slider
```

## Anatomy

```jsx
import * as Slider from '@radix-ui/react-slider';

export default () => (
  <Slider.Root>
    <Slider.Track>
      <Slider.Range />
    </Slider.Track>
    <Slider.Thumb />
  </Slider.Root>
);
```

## API Reference

### Root
Contains all the parts. Accepts `value`, `defaultValue`, `min`, `max`, `step`.

### Track / Range / Thumb
The visual rail, the filled range, and the draggable handle.

## Accessibility

Adheres to the [Slider WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/slider-multithumb).
