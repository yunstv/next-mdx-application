## Installation

```bash
npm install @radix-ui/react-popover
```

## Anatomy

```jsx
import * as Popover from '@radix-ui/react-popover';

export default () => (
  <Popover.Root>
    <Popover.Trigger />
    <Popover.Portal>
      <Popover.Content>
        <Popover.Close />
        <Popover.Arrow />
      </Popover.Content>
    </Popover.Portal>
  </Popover.Root>
);
```

## API Reference

### Trigger
The button that toggles the popover.

### Content
The container for the popover content.

### Arrow
An optional arrow pointing to the trigger.
